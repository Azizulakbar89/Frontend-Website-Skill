# WebCraft-Skill-AI

> **Desktop Website & Web App UI/UX Craft Skill** — Derived from `MobileCraft-Skill-AI`  
> Author: Ananda Azizul Akbar (`@Azizulakbar89`)

Skill ini melatih AI Coding Agent (Cursor, Windsurf, Antigravity, GitHub Copilot) untuk membangun **website desktop, SaaS dashboard, e-commerce storefront, dan landing page** yang tenang, presisi, sesuai konteks prompt (*anti-context drift*), bebas dari *AI visual slop*, dan memanfaatkan ekosistem library web terbaik di industri.
